# ElectroRent - Online Electronics Rental Platform

A beginner-friendly frontend starter project for an online electronics rental platform.

## Included
- Home
- Login/Register
- Products and categories
- Product details
- Rental cart
- Checkout
- Rental success
- My rentals
- Rental details
- Profile
- Contact/About
- Admin dashboard
- Admin product management
- Admin rental management
- Admin user management
- CSS and JavaScript

## Run locally
Open `index.html` in a browser.

## GitHub
Create a GitHub repository, upload the contents of this folder, and commit the project.

## Backend integration
The HTML forms contain example endpoints such as:
- POST `/api/users/login`
- POST `/api/users/register`
- POST `/api/rentals`

Connect these endpoints to your Java Spring Boot REST API.

## Important
This is a frontend starter. Authentication, payment processing, database persistence, validation, and security should be implemented in the Spring Boot backend before production use.
